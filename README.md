# Fastwork Selling ภาษาไทย — frontend snapshot

สำเนา frontend ที่เผยแพร่บน https://fastwork.com/th/selling เก็บ HTML, CSS, JavaScript และ asset สาธารณะที่ตรวจพบ โดยไม่รวม source project หรือ backend โค้ดและสื่อเป็นของเจ้าของเดิม

ใช้ Node.js 18 ขึ้นไป รัน `node server.js` แล้วเปิด http://127.0.0.1:4177/th/selling

บางส่วนของเว็บไซต์ต้นทางต้องใช้บริการภายนอก, backend, หรือ asset ที่ยังไม่ได้เก็บไว้ จึงอาจทำงานไม่ครบ ตรวจสอบรายการใน download-manifest.json การโหลดหน้าอาจติดต่อโดเมนภายนอกที่ต้นฉบับอ้างถึง
